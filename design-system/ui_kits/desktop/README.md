# Desktop / web app — Chronicles

Three-pane desktop layout for the **quick-capture journaling** app.

- **Sidebar** — logo, search, Dashboard + **Inbox** (with unsorted count) +
  Calendar, and a **Library** of sorted topic views (Journal, Quotes, Goals,
  Tasks, Meals, Recipes) with live counts.
- **Main** —
  - **Dashboard**: greeting, the **QuickCapture** composer, an **inbox banner**,
    and an at-a-glance widget grid (weather, wellness, meds, meals, this-week,
    custom gratitude).
  - **Inbox**: captures land here unsorted; file each into its view or dismiss.
  - **Topic view**: a Collection of that topic's entries (quotes render as
    pull-quotes, tasks toggle, etc.).
  - **Calendar**: the day's events.
- **Right rail** — weekly habit tracker, journaling streak, tags.

Captures flow into the matching Library view. Playfair + Montserrat type.
Composed from `window.ChroniclesDesignSystem_cefe3d`. Open `index.html`.
